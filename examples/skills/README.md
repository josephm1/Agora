# Folder-backed, composed Skills

Import both Markdown files through Settings → Skills → Import Markdown. Edit Clinical source
reader and replace its example `/home/agora/clinical-notes` path with your real directory, or
remove that draft folder row and choose an Android folder using the same alias. Check the folder,
then Save. The F-Droid Local Sandbox needs setup and enabling; a configured remote shell server
can be selected by its exact name. Android document folders use a read URI grant instead.

Use `/skills` to select Clinical OSCE, add a condition/question count, and explicitly Send.
Its independent `/clinical-osce` shortcut avoids replacing an existing `/osce` template shortcut.
The examiner calls the source-reader Skill through the ordinary tool loop, then conducts the
exercise in the same chat. No articles, credentials or paid test outputs are bundled.

Inspect the actual model/tool results; valid source retrieval alone does not establish clinical
or educational quality. The model obeys the instructions under the existing enabled tools; the
source-only prose is not a separate tool-permission sandbox.
