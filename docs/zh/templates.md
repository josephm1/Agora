# 交互模板

模板可以重复使用已保存的交互界面，无需让模型重新生成。请从对话抽屉打开 **交互模板**。

## 添加和管理

在完整的交互回答上选择 **另存为模板**，或在模板库中选择 **导入** 并打开 Agora 模板 JSON 文件。
导入只保存界面，不执行 JavaScript。可按名称或描述搜索，点击条目在当前对话中打开。

**操作** 菜单支持编辑、复制、从文件替换界面、导出和删除。编辑仅修改名称、描述、可选快捷命令
和关联技能文件名，不编辑 HTML 或 JavaScript。替换界面保留模板身份和元数据；失败时保留原版本。
复制生成独立模板并清除快捷命令。

## 用户定义的快捷命令

在快捷命令字段填写 `study`，发送 `/study` 即可打开对应模板。以小写字母开头，只使用小写字母、
数字和连字符，最多 64 个字符，不包含 `/`。快捷命令必须唯一，没有内置医学命令。
未知命令仍作为普通聊天消息发送。

从模板库或快捷命令打开界面在本地完成，不调用模型。请先移除附件，并等待当前回复或提交完成。
编辑或删除模板库条目不会改变对话中已保存的卡片。重新打开界面会重置控件。

## 开始 AI 工作流程

已保存模板的运行按钮会直接提交所选参数，无需第二次确认，并保留同一对话和编辑框草稿。
尚未保存为模板的生成式交互回答仍会显示提示确认。
关联技能会添加读取该技能的指令；技能文件需在技能设置中独立导入和管理。技能不存在或技能访问
关闭时不能提交，修正后可重试。

启用 **交互回答** 后，模型也可列出并打开已保存模板。这需要正常的模型和工具回合。
快捷命令和模板库打开无需模型调用。所有界面继续使用现有沙箱和大小限制。

## 备份和示例

原生导出、导入和自动备份支持 **交互模板** 类别。合并保留重复身份或快捷命令的现有条目并报告
冲突；替换仅影响选中的模板库类别。不含模板的旧备份仍兼容。技能使用原有备份类别。

在界面内上下滑动可滚动其内容，在界面外滑动可滚动聊天。到达模板顶部或底部后，继续同向滑动可滚动聊天。默认聊天卡片仅显示展开按钮；保存模板位于展开视图的工具栏中，保存成功后在本次查看期间禁用。

模板负责收集或显示数据，技能提供指令并安排流程。在设置 → 技能中配置前置、后置模板及后续技能。
在聊天输入框键入 `/` 可浏览技能。独立模板和旧模板快捷指令不会启动聊天工作流。

源码中的 `examples/interactive-templates/osce` 提供离线 Zero to Finals OSCE 测试示例。导入技能和模板后，可自行
为技能设置 `osce` 快捷命令。它不是内置命令，也不会自动连接医学资料库。


## 原生参考文件夹

在模板编辑器选择任意 Android 文件夹，应用会记住只读访问权限。默认在每次打开新的设置界面时，
在本地列出文件夹及子文件夹中的 `.md` 和 `.MD` 文件。新增文件会在下次打开时出现；已打开的菜单
保留自己的快照。浏览和预览不调用 AI，也不需要 Shell 或 Alpine。只有点击开始才读取
并附加所选文章，然后使用技能原有的指令提交 API 请求。缺失或无法读取的文件会阻止提交。

显示名称去掉扩展名，并将连字符和下划线变为空格；可指定隐藏的文件名前缀。原始路径和文件不变。
可刷新文件名、关闭自动发现以编辑明确的相对路径列表，无需单独检查文件；点击开始时会自动读取并验证所选文件。
限制为500个 Markdown 文件、八层子目录和单个参考文件128KB。导入到其他设备后需要重新连接文件夹。

“复制以供 AI 编辑”包含界面、目录配置以及桥接协议，不包含文章内容、凭据或 Android 权限 URI。
请要求返回完整的 `agora.template-edit/v1` JSON 对象，再粘贴代码。旧的纯界面 JSON 仍支持。
技能指令和模板身份保持不变。JavaScript 可以使用 `window.agoraReferences`（path、label、categories）
或 `Websandbox.connection.remote.listReferenceFiles()` 获取同一个原生目录快照。
