# 交互模板

模板可以重复使用已保存的交互界面，无需让模型重新生成。请从对话抽屉打开 **交互模板**。

## 添加和管理

在完整的交互回答上选择 **另存为模板**，或在模板库中选择 **导入** 并打开 Agora 模板 JSON 文件。
导入只保存界面，不执行 JavaScript。可按名称或描述搜索，点击条目在当前对话中打开。

**操作** 菜单支持编辑、复制、从文件替换界面、导出和删除。编辑仅修改名称、描述、可选快捷命令
和关联技能文件名，不编辑 HTML 或 JavaScript。替换界面保留模板身份和元数据；失败时保留原版本。
复制生成独立模板并清除快捷命令。

## 用户定义的快捷命令

在快捷命令字段填写 `study`，发送 `/study` 即可打开对应模板。以小写字母开头，只使用小写字母、
数字和连字符，最多 64 个字符，不包含 `/`。快捷命令必须唯一，没有内置医学命令。
未知命令仍作为普通聊天消息发送。

从模板库或快捷命令打开界面在本地完成，不调用模型。请先移除附件，并等待当前回复或提交完成。
编辑或删除模板库条目不会改变对话中已保存的卡片。重新打开界面会重置控件。

## 开始 AI 工作流程

界面的按钮可提交所选参数。Agora 会先展示完整提示供确认，再发送到同一对话，保留编辑框草稿。
关联技能会添加读取该技能的指令；技能文件需在技能设置中独立导入和管理。技能不存在或技能访问
关闭时不能提交，修正后可重试。

启用 **交互回答** 后，模型也可列出并打开已保存模板。这需要正常的模型和工具回合。
快捷命令和模板库打开无需模型调用。所有界面继续使用现有沙箱和大小限制。

## 备份和示例

原生导出、导入和自动备份支持 **交互模板** 类别。合并保留重复身份或快捷命令的现有条目并报告
冲突；替换仅影响选中的模板库类别。不含模板的旧备份仍兼容。技能使用原有备份类别。

在聊天输入框键入 `/` 可显示所有已保存模板；继续输入可按名称或快捷指令筛选。
点击模板即可直接打开本地界面，无需先调用模型或预先指定快捷指令。
发送唯一匹配名称的斜杠指令也可直接打开模板；多个或零个匹配均不会调用模型。

源码中的 `examples/interactive-templates/osce` 提供离线 Zero to Finals OSCE 测试示例。导入技能和模板后，可自行
设置 `osce` 快捷命令。它不是内置命令，也不会自动连接医学资料库。
